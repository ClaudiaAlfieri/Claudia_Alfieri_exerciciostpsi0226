## 📌 About This Repository

This repository contains exercises and theory notes on **Python** developed during the **CET TPSI** programme at **ATEC — Academia de Formação**.

Each folder corresponds to a topic or set of exercises covered in class, organized progressively as the course material advances. 🎯

---

## 🧠 Concepts Covered

- ✅ Variables, Data Types and Operators
- ✅ Control Flow (`if`, `elif`, `else`)
- ✅ Loops (`for`, `while`)
- ✅ Functions and Scope
- ✅ Strings and String Manipulation
- ✅ Lists, Tuples and Dictionaries
- ✅ Exception Handling (`try`, `except`)
- ✅ File I/O
- ✅ Libraries (`os`, `math`, `random`, etc.)

---

## 🛠️ Technologies

- **Language:** Python 3
- **IDE:** VS Code
- **Version control:** Git + GitHub

---

## ▶️ How to Run

1. Clone the repository:
```bash
git clone https://github.com/teu-usuario/python-tpsi.git
```

2. Open the project in your preferred IDE

3. Navigate to the desired exercise folder and run:
```bash
python main.py
```
